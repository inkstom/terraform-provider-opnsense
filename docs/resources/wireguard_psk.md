# opnsense_wireguard_psk (Resource)

Generates a WireGuard pre-shared key on the firewall (`/api/wireguard/client/psk`). Nothing is stored on OPNsense; the key lives in Terraform state. Feed it into `opnsense_wireguard_client.psk`.

## Example Usage

```terraform
resource "opnsense_wireguard_psk" "laptop" {}

resource "opnsense_wireguard_client" "laptop" {
  name           = "laptop"
  public_key     = var.laptop_public_key
  psk            = opnsense_wireguard_psk.laptop.psk
  tunnel_address = ["10.99.0.2/32"]
}
```
