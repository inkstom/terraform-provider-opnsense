# opnsense_gateway_group (Resource)

Gateway groups combine gateways into tiers for failover and load balancing (System > Gateways > Group). Requires OPNsense 26.7 or later. A group cannot be deleted while it is referenced, e.g. by a firewall rule.

## Example Usage

```terraform
# Failover: use WAN_DHCP; fall back to WAN2_GW when it's down or lossy
resource "opnsense_gateway_group" "failover" {
  name    = "WAN_FAILOVER"
  trigger = "downloss"
  tiers = [
    ["WAN_DHCP"],
    [opnsense_gateway.wan2.name],
  ]
}

# Load balancing: both gateways in the same tier
resource "opnsense_gateway_group" "balanced" {
  name         = "WAN_LB"
  pool_options = "round-robin sticky-address"
  tiers        = [["WAN_DHCP", opnsense_gateway.wan2.name]]
}
```

## Schema

### Required

- `name` (String) Group name. Letters, digits, `_` and `-` only, max 32 characters. Firewall rules refer to the group by this name.
- `tiers` (List of Set of String) Ordered list of tiers (*Tier 1* to *Tier 5* in OPNsense), each a set of gateway **names**. The first element is tier 1 (highest priority). Gateways in the same tier load-balance; lower tiers are used when all gateways in the higher tiers are down. Between 1 and 5 tiers. Example: `[["WAN1_DHCP"], ["WAN2_DHCP"]]` for failover.

### Optional

- `description` (String) You may enter a description here for your reference (not parsed).
- `pool_options` (String) Default: Round Robin, Sticky Address determined by advanced settings. Round Robin: Loops through the translation addresses. Sticky Address: The Sticky Address option can be used with the Round Robin pool type to ensure that a particular source address is always mapped to the same translation address. One of `""` (Default), `round-robin` (Round Robin) or `round-robin sticky-address` (Round Robin with Sticky Address). Defaults to `""`.
- `trigger` (String) When to trigger exclusion of a member. One of `down` (Member Down), `downloss` (Packet Loss), `downlatency` (High Latency) or `downlosslatency` (Packet Loss and High Latency). Defaults to `down`.

### Read-Only

- `id` (String) UUID of the gateway group.
