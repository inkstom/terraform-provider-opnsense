# opnsense_routing_gateway_group (Resource)

Gateway groups combine gateways into tiers for failover and load balancing (System > Gateways > Group). Requires OPNsense 26.7 or later. Requires OPNsense 26.7 or later. A group cannot be deleted while it is referenced, e.g. by a firewall rule.

## Example Usage

```terraform
# Failover: use WAN_DHCP; fall back to WAN2_GW when it's down or lossy
resource "opnsense_routing_gateway_group" "failover" {
  name    = "WAN_FAILOVER"
  trigger = "downloss"
  tiers = [
    ["WAN_DHCP"],
    [opnsense_routing_gateway.wan2.name],
  ]
}

# Load balancing: both gateways in the same tier
resource "opnsense_routing_gateway_group" "balanced" {
  name         = "WAN_LB"
  pool_options = "round-robin sticky-address"
  tiers        = [["WAN_DHCP", opnsense_routing_gateway.wan2.name]]
}
```

## Schema

### Required

- `name` (String) Group name. Letters, digits, `_` and `-` only, max 32 characters. Firewall rules refer to the group by this name.
- `tiers` (List of Set of String) Ordered list of tiers, each a set of gateway **names**. The first element is tier 1 (highest priority). Gateways in the same tier load-balance; lower tiers are used when all gateways in the higher tiers are down. Between 1 and 5 tiers. Example: `[["WAN1_DHCP"], ["WAN2_DHCP"]]` for failover.

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `pool_options` (String) Load-balancing pool option: `""` (default), `round-robin` or `round-robin sticky-address`. Defaults to `""`.
- `trigger` (String) When to consider a member down: `down` (member down), `downloss` (packet loss), `downlatency` (high latency) or `downlosslatency` (packet loss or high latency). Defaults to `down`.

### Read-Only

- `id` (String) UUID of the gateway group.
